# Голосок – локальное распознавание аудио в текст для Mac

> **Локальный транскрибатор речи для macOS на базе Sber GigaAM v3.**  
> Быстрый голосовой ввод по `⌥ + Space` и расшифровка файлов без интернета, подписок и отправки данных на внешние сервера.

---

### ⚡ Ключевые возможности

* **100% Офлайн:** Инференс на чипах Apple Silicon (M1–M5) с аппаратным ускорением CoreML / ANE.
* **Вставка под курсор:** Нажмите `⌥ + Space` в любом окне (Notion, VS Code, Telegram, Obsidian) — готовый текст сразу появится под курсором.
* **Работа с медиа:** Транскрибация файлов MP3, WAV, M4A, MP4 любой длины.
* **Понимание контекста:** Корректная обработка IT-сленга, рунглиша и автоматическая расстановка пунктуации.

---

## Установка и запуск

### 1. Скачивание
1. Заберите актуальный `Golosok.dmg` из раздела **[Releases](../../releases)**.
2. Перетащите `Golosok.app` в папку `/Applications`.

### 2. Обход Gatekeeper
Приложение распространяется как Open Source без платной подписи Apple Developer ID. Чтобы снять карантин macOS, выполните одну команду в Терминале:

```bash
xattr -cr /Applications/Golosok.app
> ```

Или через GUI: Control + Правый клик по иконке в /Applications $\rightarrow$ Открыть $\rightarrow$ Подтвердить.

## Настройка разрешений

При старте откроется окно **«Настройка Голоска»**. Потребуются 2 права:

1. **Доступ к микрофону**
   * Нажмите **«Включить»** $\rightarrow$ Подтвердите в системном попе-апе macOS.
2. **Универсальный доступ** (для автовставки через `Cmd + V`)
   * Нажмите **«Настройки»** (откроется *Системные настройки $\rightarrow$ Конфиденциальность и безопасность $\rightarrow$ Универсальный доступ*).
   * Включите тумблер напротив **Golosok**.
   * *(Если тумблер был активен от старой версии — удалите приложение из списка через `-` и добавьте заново).*

Как только индикаторы станут зелёными, нажмите **«Начать использование»**.

## Горячие клавиши

Приложение работает в фоновом режиме из любого места системы:

* **`Option + Space` (`⌥ + Пробел`)** — Старт / Стоп диктовки
  * **1-е нажатие:** Появляется белый островок с зелёным эквалайзером. Говорите.
  * **2-е нажатие:** Островок меняет цвет на фиолетовый (инференс ~0.1 сек), текст автоматически вставляется в активное поле (Telegram, IDE, браузер, Заметки).
* **`Escape` (`ESC`)** — Отмена
  * Мгновенно сбрасывает запись без вставки текста.

## Меню-бар

Иконка `waveform` в верхнем правому углу (возле часов):

* **Скопировать последнюю запись** — Забрать последний результат в буфер.
* **Открыть окно истории** — Просмотр всех прошлых диктовок и управление ими.
* **Завершить** — Выход из приложения.

## 📋 Спецификация

| Параметр | Значение |
| :--- | :--- |
| **ОС** | macOS 13.0+ (Ventura, Sonoma, Sequoia) |
| **Архитектура** | Apple Silicon (M1 / M2 / M3 / M4 / M5) |
| **Нейросеть** | GigaAM v3 RNN-T (GGUF Q8_0) |
| **RAM (фон)** | ~30–50 МБ |
| **RAM (инференс)** | ~300 МБ |
| **Размер дистрибутива** | ~250 МБ |


## 🛠 Сборка из исходников

open Golosok.xcodeproj
